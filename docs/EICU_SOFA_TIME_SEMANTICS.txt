E05 MODIFIED SOFA: COMPONENTS, MISSINGNESS AND TIME SEMANTICS

Overall construct
- sepsis_sofa = sofa_resp + sofa_coag + sofa_liver + sofa_cardio + sofa_cns + sofa_renal.
- Each component was coalesced to 0 when the component SQL returned NULL before summation.
- Inclusion required sepsis_sofa>=2.
- It was an absolute modified first-day score; there was no individualized baseline SOFA subtraction.

Respiratory
- Source: eicu_crd.apacheapsvar.pao2, fio2 and vent.
- P/F thresholds: <100 with vent=1 ->4; <200 with vent=1 ->3; <300 ->2; <400 ->1; otherwise 0.
- FiO2>1 was treated as percent and divided by 100; FiO2<=1 was used as a fraction.
- Missing PaO2, missing FiO2, or FiO2<=0 ->0.
- Exact measurement timestamps are not stored in the derived e05 object and cannot be proven pre-T0.

Coagulation
- Source: eicu_crd.lab.
- Window: labresultoffset 0 to 1,440 minutes.
- Labels: lower(labname) matching platelet or plt.
- Value filter: 1 to 2,000; minimum value used.
- Thresholds: <20 ->4; <50 ->3; <100 ->2; <150 ->1; otherwise/missing ->0.

Liver
- Source: eicu_crd.apacheapsvar.bilirubin.
- Thresholds: >=12 ->4; >=6 ->3; >=2 ->2; >=1.2 ->1; otherwise/missing ->0.
- Exact measurement timestamp cannot be proven pre-T0 from e05.

Cardiovascular
- Source: e06_normalized_rows plus eicu_crd.apacheapsvar.meanbp.
- Vasopressor window: infusionoffset 0 to 1,440 minutes; maximum usable positive NE-equivalent rate.
- max NE-equivalent >0.1 ->4; >0 ->3; otherwise meanbp<70 ->1; otherwise/missing ->0.
- The component has no score-2 branch in the original algorithm.
- This is a first-day measure and is not guaranteed to precede pressor-first T0.

CNS
- Source: eicu_crd.apacheapsvar.eyes, motor and verbal.
- Missing subcomponents were individually coalesced to 0 before summation.
- Sum <6 ->4; <10 ->3; <13 ->2; <15 ->1; otherwise 0.
- Consequently, missing GCS subcomponents do not behave as neutral missingness.
- Exact measurement timestamps cannot be proven pre-T0 from e05.

Renal
- Source: eicu_crd.apacheapsvar.creatinine and urine.
- Creatinine: >=5 ->4; >=3.5 ->3; >=2 ->2; >=1.2 ->1; otherwise/missing ->0.
- Urine: <200 ->4; <500 ->3; otherwise/missing ->0.
- Renal score was the greater of creatinine and urine scores.
- Exact component timestamps cannot be proven pre-T0 from e05.

Downstream interpretation
- e05 SOFA was suitable only as the recovered cohort organ-dysfunction rule and as a supplementary severity variable with timing limitations.
- It must not be described as a fully pre-T0 SOFA.
- S8 remains labelled as a supplementary severity analysis with component timing not fully verified.
- No new SOFA reconstruction, threshold, sensitivity analysis or model was run in this closure task.
